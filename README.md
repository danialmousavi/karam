## ✨ ویژگی‌ها

### 📋 مدیریت کارها
- ✅ **مدیریت تسک‌ها** - افزودن، ویرایش، حذف و تیک زدن تسک‌ها
- 📅 **تقویم فارسی** - نمایش تسک‌ها در تقویم شمسی با قابلیت انتخاب روز
- 📂 **دسته‌بندی‌ها** - ایجاد دسته‌بندی‌های سفارشی با آیکون و رنگ‌های متنوع
- 🔔 **یادآوری‌ها** - تنظیم یادآوری با آلارم برای هر تسک
- ⏰ **یادآوری روزانه** - تنظیم ساعت یادآوری روزانه برای بررسی کارها
- 📊 **گروه‌بندی بر اساس تاریخ** - نمایش تسک‌ها بر اساس روزهای مختلف

### 📝 مدیریت یادداشت‌ها
- 📂 **پوشه‌ها** - ایجاد پوشه‌های مختلف برای دسته‌بندی یادداشت‌ها
- ✏️ **یادداشت‌ها** - افزودن، ویرایش و حذف یادداشت‌ها در هر پوشه
- 🎨 **رنگ‌بندی** - انتخاب رنگ دلخواه برای هر یادداشت

### 🎨 ظاهر و شخصی‌سازی
- 🌙 **حالت تاریک** - پشتیبانی کامل از دارک مود با همگام‌سازی با سیستم
- 🎨 **تم‌های رنگی** - ۵ تم رنگی مختلف با نسخه دارک مود
- 🌐 **پشتیبانی از زبان فارسی** - رابط کاربری کاملاً فارسی
- 📱 **سازگار با iOS و Android** - رابط کاربری یکپارچه در هر دو پلتفرم

### 💾 مدیریت داده
- 💾 **ذخیره‌سازی محلی** - استفاده از SQLite برای ذخیره‌سازی داده‌ها
- 📤 **پشتیبان‌گیری** - خروجی گرفتن از تمام داده‌ها
- 🔄 **بازیابی** - بازیابی داده‌ها از فایل پشتیبان

## 📥 نصب و راه‌اندازی

### پیش‌نیازها

- Node.js (نسخه ۱۶ یا بالاتر)
- npm یا yarn
- Expo CLI
- گوشی اندروید یا iOS با اپلیکیشن Expo Go

### مراحل نصب

```bash
# ۱. کلون کردن پروژه
git clone https://github.com/danialmousavi/karam.git
cd karam

# ۲. نصب وابستگی‌ها
npm install
# یا
yarn install

# ۳. نصب پکیج‌های اضافی
npx expo install react-native-safe-area-context
npx expo install expo-notifications
npx expo install expo-splash-screen
npx expo install expo-sqlite
npx expo install expo-font
npx expo install @react-native-async-storage/async-storage

# ۴. اجرای برنامه
npm start
# یا
npx expo start
```

## 📱 اجرا روی دستگاه

### روش اول: با اپلیکیشن Expo Go (ساده‌ترین روش)

1. **نصب اپلیکیشن Expo Go**:
   - [اندروید (Google Play)](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - [iOS (App Store)](https://apps.apple.com/app/expo-go/id982107779)

2. **اجرای برنامه**:
   ```bash
   npx expo start
   ```
   یا
   ```bash
   npm start
   ```

3. **اتصال دستگاه**:
   - **اسکن QR Code**: اپلیکیشن Expo Go را باز کنید و QR Code نمایش داده شده را اسکن کنید
   - **اتصال USB**: دستگاه را با USB به کامپیوتر وصل کنید و در اپ Expo Go گزینه "Tunnel" را انتخاب کنید

### روش دوم: روی شبیه‌ساز اندروید

```bash
# نصب Android Studio و تنظیم AVD
# سپس اجرا با:
npx expo start --android
# یا
npm run android
```

### روش سوم: روی شبیه‌ساز iOS (فقط در مک)

```bash
# نصب Xcode و تنظیم شبیه‌ساز
# سپس اجرا با:
npx expo start --ios
# یا
npm run ios
```

## 🎨 تم‌های رنگی

برنامه شامل ۵ تم رنگی مختلف است:

| تم | رنگ اصلی | توضیح |
|----|---------|--------|
| 🌞 **پیش‌فرض** | سبز پاستیلی | تم اصلی و آرام‌بخش |
| 🌊 **اقیانوسی** | آبی | حس عمق و آرامش |
| 🌸 **اسطوخودوس** | بنفش | حس رویایی و شیک |
| 🌅 **غروب** | نارنجی | گرم و پرانرژی |
| 🌲 **جنگلی** | سبز تیره | طبیعی و زمینی |

هر تم دارای نسخه دارک مود نیز می‌باشد.

## 📱 صفحات برنامه

### 🏠 صفحه خانه
- نمایش تقویم کشویی روزها
- لیست تسک‌های روز انتخاب شده
- افزودن تسک جدید با قابلیت انتخاب چند روز
- تنظیم یادآوری با زمان دلخواه
- نمایش دسته‌بندی و زمان هر تسک

### 📅 صفحه تقویم
- نمایش ماهانه تقویم شمسی
- انتخاب روز و مشاهده تسک‌های آن روز
- افزودن تسک برای روزهای خاص
- نمایش نقطه زیر روزهای دارای تسک

### 📂 صفحه دسته‌بندی‌ها
- ایجاد دسته‌بندی با آیکون و رنگ دلخواه
- نمایش تعداد تسک‌های باقی‌مانده در هر دسته
- کلیک روی هر دسته برای مشاهده تسک‌های مربوطه
- حذف دسته‌بندی با حذف تمام تسک‌های مربوطه

### 📝 صفحه یادداشت‌ها
- **پوشه‌ها**: ایجاد پوشه‌های مختلف برای دسته‌بندی یادداشت‌ها
- **یادداشت‌ها**: افزودن، ویرایش و حذف یادداشت‌ها در هر پوشه
- **رنگ‌بندی**: انتخاب رنگ دلخواه برای هر یادداشت

### ⚙️ صفحه تنظیمات
- **ظاهر**: تغییر تم رنگی، فعال/غیرفعال کردن حالت تاریک، همگام‌سازی با سیستم
- **یادآوری**: تنظیم ساعت یادآوری روزانه
- **مدیریت داده**: حذف تمام داده‌ها
- **بیشتر**: اشتراک‌گذاری اپ، ارسال بازخورد، امتیاز دادن
- **درباره**: اطلاعات برنامه و حریم خصوصی
